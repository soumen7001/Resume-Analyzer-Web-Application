About This Project

AI Resume Analyzer

An NLP-powered platform built to help job seekers optimize their resumes and land more interviews through intelligent analysis and actionable insights.

🎯 What Does the Resume Analyzer Do?

The Resume Analyzer is a full-stack web application that uses Natural Language Processing (NLP) and Machine Learning techniques to evaluate your resume and provide comprehensive insights.

Key capabilities:

  • ATS Compatibility Scoring — Evaluates how well your resume performs with Applicant Tracking Systems across 7 weighted dimensions
  • Job Description Matching — Compares your resume against job descriptions using TF-IDF vectorization and cosine similarity
  • Skills Detection — Identifies 200+ technical and soft skills from your resume using regex pattern matching
  • Keyword Analysis — Extracts and compares important keywords, highlighting matches and gaps
  • Section Detection — Identifies contact info, education, experience, projects, and certifications
  • Improvement Suggestions — Generates prioritized, actionable recommendations
  • Downloadable Report — Export your full analysis as a text report

⚙️ How Does the Analysis Work?

The analysis engine uses a multi-stage pipeline of NLP and ML techniques:

  1. Text Extraction — pdfplumber (PDF) and python-docx (DOCX) extract raw text
  2. Section Parsing — Regex-based section detection for contact info, education, experience, skills, projects, and certifications
  3. Skills Detection — Pattern matching against a curated database of 200+ technical and soft skills
  4. ATS Scoring — Weighted scoring across 7 categories: contact info, skills, experience, education, projects, certifications, and formatting
  5. TF-IDF Vectorization — scikit-learn converts resume and job description text to numerical feature vectors
  6. Cosine Similarity — Measures the semantic angle between resume and job description vectors
  7. Keyword Overlap — Jaccard-style keyword matching for interpretable match percentages
  8. Suggestions Engine — Rule-based system generates personalized improvement recommendations

🏗️ Project Architecture

Clean, modular architecture designed for scalability — ready for database integration and LLM upgrades:

resume-analyzer/
├── index.html          ← Home page
├── analyzer.html       ← Upload & analyze page
├── results.html        ← Results dashboard (tab-based)
├── about.html          ← This page
├── css/
│   └── style.css       ← Premium responsive styles
├── js/
│   ├── script.js       ← Shared: navbar, notifications, health check
│   ├── analyzer.js     ← Analyzer page: upload, API call, localStorage
│   └── results.js      ← Results page: render all sections, animations
└── backend/
    ├── app.py          ← Flask API (CORS-enabled)
    ├── resume_parser.py← Text extraction (PDF/DOCX)
    ├── analyzer.py     ← Scoring, TF-IDF, suggestions
    ├── requirements.txt← Python dependencies
    └── uploads/        ← Temp file storage (auto-cleaned)

API Endpoints:

  • POST /upload-resume — Upload and parse a resume file
  • POST /analyze-resume — Full analysis (with optional job description)
  • POST /match-job — Match resume text against job description
  • GET /health — Health check endpoint
  • GET /api/skills — Skills database for autocomplete
  • GET /api/analyze-sample — Demo analysis without uploading
